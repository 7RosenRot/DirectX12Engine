## Annotation


### Application layer

  *Задача*: Создать окно, слушать ввод, использовать нижележащий уровень абстракции
  
  *Примечание*: Маскимально близко к самой ОС

#### main.cpp
---
1. *Назначение*
  - Точка входа в `WinApp (wWinMain)`. Создаёт корневой объект движка, задает параметры экрана и запускает основной цикл.
2. *Владеет*
  - Временно владеет объектом ядра Kernel на стеке функции wWinMain.
3. *Подчиняется*
  - Запускается непосредственно Windows ОС.

---
#### Window class
---
1. *Назначение*
  - Отвечает за создание и обслуживание стандартного `Win32-окна` приложения. Обеспечивает регистрацию класса окна, показ на экране и обработку входящих событий ОС (системных сообщений) через оконную процедуру `WndProc`. Перенаправляет события изменения размеров и ввода в соответствующие подсистемы.
2. *Владеет*
  - Статическим дескриптором окна `m_hwnd (HWND)`.
  - Булевым флагом состояния работы приложения `m_isRunning`.
  - Вызывает обработчик сообщений `ImGui (ImGui_ImplWin32_WndProcHandler)` и передает события в `Input`, `Kernel` и `DirectX12Graphics`.
3. *Подчиняется*
  - Инстанцируется и настраивается внутри Kernel.
  - Оконная процедура WndProc вызывается операционной системой Windows при отправке сообщений окну.

---
#### Kenrel class
---
1. *Назначение*
  - Главный диспетчер движка. Объединяет все ключевые подсистемы, управляет их инициализацией, координирует итерации главного цикла рендеринга (RenderFrame), опрашивает очередь сообщений Windows и корректно освобождает ресурсы при выходе.
2. *Владеет*
  - Управляет временем жизни основных подсистем движка через `std::unique_ptr`:
    - `DirectX12Graphics (m_pRenderer)`.
    - `AssetManager (m_pAssetManager)`.
    - `Scene (m_pScene)`.
    - `EngineUI (m_pEngineUI)`.
    - `Window (m_pWindow)`.
  - Хранит глобальные параметры окна `Width`, `Height`, `Name` и статические указатели на собственные инстансы для глобального доступа из оконной процедуры.
3. *Подчиняется*
  - Управляется напрямую из точки входа `main.cpp`.

#### Input class
1. *Назначение*
  - Статический глобальный класс для отслеживания и обработки пользовательского ввода: фиксация зажатых клавиш, расчёт смещения мыши между кадрами `Mouse Delta`, захват и скрытие курсора в центре экрана.
2. *Владеет*
  - Не имеет экземпляров - конструктор удален.
  - Содержит статические структуры данных:
    - Массив состояния клавиш `m_Keys[256]`
    - Флаги блокировки курсора `m_MouseLocker` и активации средней кнопки m_MmbMode
    - Величина смещения мыши `m_MouseDeltaX`, `m_MouseDeltaY`, `m_MouseWheelDelta`.
3. *Подчиняется*
  - События ввода поставляются из `Window::WndProc`.
  - Опрос состояния ввода производится компонентами сцены и камерой `Camera`.

### Framework layer
  *Задача*: Создать и управлять камерой, хранить массив моделей, использовать нижележащий уровеньабстракции
  *Примечание*: Граничный уровень между UI и Graphics API

#### Tarnsform class
1. *Назначение*
  - Представляет пространственные характеристики объекта в 3D (позиция, поворот в углах Эйлера, масштаб). Решает математические задачи перемещения объектов вдоль осей, вращения, облета вокруг цели (Orbiting), а также построения модельных матриц (Scale-Rotate-Translate) и матриц вида (View Matrix) для камеры.
2. *Владеет*
  - Векторами положения (m_Position), вращения (m_Rotation), масштаба (m_Scale).
  - Векторами направления ориентации в пространстве: вперёд (m_Look), вправо (m_Right), вверх (m_Up).
  - Использует математическую библиотеку DirectXMath.
3. *Подчиняется*
  - Является встроенным компонентом классов GameObject и Camera.

#### GameObject class
1. *Назначение*
  - Описывает отдельный игровой или редакторский объект на 3D-сцене. Объединяет геометрию (Model), материал (Texture) и пространственные координаты (Transform) в единую логическую сущность.
2. *Владеет*
  - Экземпляром Transform для позиционирования.
  - Умными указателями std::shared_ptr на ресурсы геометрии Model (m_Model) и текстуры Texture (m_Texture).
  - Строками с именем объекта и путями к файлам моделей и текстур.
  - Финальной матрицей трансформации модели m_ModelMatrix (XMMATRIX).
  - Хранит слабый (сырой) указатель на AssetManager для загрузки ресурсов.
3. *Подчиняется*
  - Создаётся, хранится и удаляется внутри Scene.
  - Выбирается и модифицируется в интерфейсе EngineUI.

#### Scene class
1. *Назначение*
  - Представляет виртуальный трехмерный мир. Решает задачи менеджмента всех игровых объектов (создание, удаление, поиск), обновления состояния камеры, сериализации (сохранения/загрузки формата сцены .rose в текстовый файл) и инициирования отрисовки объектов через рендерер с учетом выделения.
2. *Владеет*
  - Контейнером объектов m_GameObjects (std::unordered_map пар имя-объект).
  - Экземпляром активной камеры Camera.
  - Ссылкой на AssetManager.
3. *Подчиняется*
  - Напрямую контролируется Kernel (инициализация, обновление кадра, удаление).
  - Взаимодействует с EngineUI для импорта мешей и сохранения/загрузки.

#### AssetManager class
1. *Назначение*
  - Отвечает за загрузку с диска и кэширование разделяемых графических ресурсов (моделей и текстур), предотвращая дублирование в памяти видеокарты. Управляет выделенным контекстом загрузки (UploadContext) для копирования байтов из ОЗУ в видеопамять.
2. *Владеет*
  - Кэш-таблицами загруженных ресурсов m_Model и m_Texture (std::unordered_map путей к умным указателям).
  - Указателем на текстуру по умолчанию m_pDefaultTexture (однотонная серая заглушка, используемая при сбоях загрузки).
  - Временным контекстом копирования CommandContext для трансфера данных на GPU.
  - Ссылками на D3D12-устройство, аллокатор дескрипторов и очередь команд.
3. *Подчиняется*
  - Создаётся и уничтожается в Kernel.
  - Вызывается из GameObject и EngineUI для загрузки сеток/текстур.

#### Camera class
1. *Назначение*
  - Описывает точку обзора в 3D-пространстве. Реализует два режима навигации:
    - Свободный обзор (FPS-стиль): перемещение на WASD и вращение мышью.
    - Редакторский режим (Orbit/Pan): вращение вокруг выбранной точки фокуса (цели орбиты), панорамирование (Shift + средняя кнопка мыши) и масштабирование расстояния колесом мыши.
2. *Владеет*
  - Математическим представлением положения Transform.
  - Точкой фокуса вращения m_OrbitTarget (XMFLOAT3).
  - Матрицами проекции (m_MatrixProjection) и вида (m_MatrixView).
3. *Подчиняется*
  - Находится внутри Scene.
  - Управляется через метод InputProcessing, вызываемый при обновлении сцены.
  - Синхронизируется по Aspect Ratio при изменении размеров вьюпорта редактора в EngineUI.

#### EngineUI class
1. *Назначение*
  - Реализует графический интерфейс редактора на базе Dear ImGui и ImGuizmo. Отвечает за:
    - Компоновку окон (Dockspace): "Viewport" сцены, "Browser" файлов, "Properties" параметров.
    - Логику выделения объектов кликом мыши по вьюпорту методом трассировки лучей (Raycasting по  полигонам модели на CPU).
    - Манипуляции над объектами в пространстве с помощью 3D-гизмо (перемещение, поворот, масштаб).
    - Горячие клавиши отмены (Ctrl+Z, Ctrl+Y) и удаления (Delete).
2. *Владеет*
  - Контейнером выделенных объектов m_pSelectedObject (std::vector<std::shared_ptr<GameObject>>).
  - Историей команд CommandHistory для отката/повтора.
  - Иконками инструментов манипуляции (m_pIconMove, m_pIconRotate, m_pIconScale).
  - Дескриптором шрифта ImGui в куче SRV (m_FontAllocation).
  - Переменными состояния гизмо-трансформаций и исходными буферами координат для отката изменений.
3. *Подчиняется*
  - Инстанцируется, обновляется и рендерится внутри Kernel.
  - Вызовы отрисовки напрямую встраиваются в цикл кадра рендерера.

#### History class
  Представляет собой семейство классов, выполняющих регистрацию последовательности пользовательских комманд. Состоит из модулей:
##### ICommand
1. *Назначение*
  - Общий интерфейс, наследуемый потомками
##### TransformCommand
1. *Назначение*
  - Сохраняет изменение координат одиночного объекта.
2. *Владеет*
  - Ссылкой m_pObject на игровой объект и копиями матриц трансформации m_OldTransform, m_NewTransform
##### MultiTransformCommand
1. *Назначение*
  - Сохраняет групповые изменения координат нескольких объектов.
2. *Владеет*
  - Списком указателей на объекты и массивами их старых/новых трансформаций.
##### DeleteCommand
1. *Назначение*
  - Обеспечивает удаление группы объектов из сцены с возможностью их полного восстановления на прежние места со всеми ресурсами.
2. *Владеет*
  - Указателем на Scene и списком удаленных объектов (удерживая их от полного уничтожения в памяти через std::shared_ptr).
##### CommandHistory
1. *Назначение*
  - Управляет стеками истории отмены (Undo) и повтора (Redo) действий пользователя.
2. *Владеет*
  - CommandHistory: Двумя векторами m_UndoStack и m_RedoStack уникальных указателей std::unique_ptr<ICommand>.
3. *Подчиняется*
  - Встроен в EngineUI для фиксации действий редактора.

#### Logger class
1. *Назначение*
  - Синглтон-логгер для вывода диагностических сообщений, ошибок и предупреждений движка в файл (Engine.log) и в окно вывода отладчика Visual Studio (OutputDebugString). Помогает отслеживать падения шейдеров или сбои инициализации Direct3D. В данный момент не используется.
2. *Владеет*
  - Файловым потоком вывода m_logFile (std::ofstream).
  - Булевым флагом состояния инициализации.
3. *Подчиняется*
  - Доступен глобально из любого файла проекта через вспомогательные макросы ENGINE_LOG_INFO, ENGINE_LOG_WARNING и др. в Debug-сборке.

### Renderer layer
  *Задача*: Вызвать низкоуровневые классы и забрать у них готовый результат
  *Примечание*: Отвечает только за графику. Не знает ни количестве моделей, ни о камере, ни о чем-либо другом

#### DirectX12Graphics class
1. *Назначение*
  - Высокоуровневая обертка над графическим конвейером DirectX 12. Решает задачи инициализации D3D-устройства, выбора видеоадаптера, создания аллокаторов куч дескрипторов, сборки конвейерных состояний (PSO), пересоздания буферов глубины/цвета RTT при изменении размеров экрана, а также управления проходами рендеринга (очистка буферов, отрисовка мешей, трафаретная отрисовка выделенных объектов, подготовка контекста интерфейса).
2. *Владеет*
  - Ключевыми ресурсами Direct3D 12: устройством m_device (ID3D12Device), фабрикой factory4.
  - Компонентами RHI-архитектуры через std::unique_ptr:
    - Очередью команд CommandQueue (m_cmdQueue).
    - Цепочкой вывода SwapChain (m_SwapChain).
    - Пулом контекстов команд CommandContextPool (m_cmdContextPool).
    - Аллокаторами куч дескрипторов DescriptorAllocator для SRV, RTV и DSV.
  - Конфигурациями пайплайна:
    - Сигнатурой корня RootSignature (m_rootSignature).
    - Набором PSO GraphicsPSO (стандартный рендер, отрисовка трафарета маски, рендер обводки аутлайна).
  - Буферами кадра:
    - Текстурой рендеринга ColorBuffer (m_SceneTexture) для RTT-сцены.
    - Текстурой глубины/трафарета DepthBuffer (m_DepthBuffer).
  - Владеет указателем на текущий записываемый контекст кадра m_pFrameContext.
3. *Подчиняется*
  - Инстанцируется и вызывается внутри Kernel.
  - Предоставляет ссылки на девайс и аллокаторы для AssetManager и EngineUI.

#### Model class
1. *Назначение*
  - Отвечает за загрузку 3D-геометрии формата Wavefront OBJ, построение вершинных/индексных буферов на GPU и их отрисовку. Парсит текстовый файл на составляющие координат вершин, текстурных координат и нормалей, генерирует плоский массив вершинных структур движка и связывает вершинные/индексные представления (Views).
2. *Владеет*
  - GPU-буферами GpuBuffer вершин (m_VertexBuffer) и индексов (m_IndexBuffer).
  - Представлениями буфера вершин (m_VertexBufferView) и индекса (m_IndexBufferView).
  - Объемом индексов для рендеринга m_IndexCount.
  - CPU-копиями вершинных и индексных массивов (m_Vertices, m_Indices) для просчета пересечений лучей на CPU.
3. *Подчиняется*
  - Создается и хранится как разделяемый ресурс в AssetManager.
  - Ссылка на модель используется GameObject для связи со сценой.
  - Отрисовывается методами DirectX12Graphics в цикле кадра.

#### Texture class
1. *Назначение*
  - Описывает 2D-изображение (диффузную карту текстуры) для наложения на 3D-модели. Загружает форматы (PNG, JPG) с использованием сторонней библиотеки stb_image, пересылает сырые пиксели на GPU и связывает их с дескриптором SRV. Позволяет быстро биндиться на корневую сигнатуру.
2. *Владеет*
  - COM-ресурсом текстуры на GPU m_Texture (ID3D12Resource).
  - Промежуточным буфером копирования m_UploadHeap (ID3D12Resource).
  - Аллокацией представления ресурса m_SrvAllocation (CPU/GPU хэндлы дескриптора SRV).
3. *Подчиняется*
  - Загружается и кэшируется в AssetManager.
  - Ссылается из GameObject для наложения текстуры на меш.
  - Активируется (Bind) непосредственно перед вызовами отрисовки модели в DirectX12Graphics.

### RHI layer
  *Задача*: Обеспечить выделение памяти под струтуры и заполнение их данными
  *Примечание*: Самый низкйи уровень. Взаимодействие с GPU, выделение памяти, создание структур

#### CommandContext class
1. *Назначение*
  - Обертка над списком команд (ID3D12GraphicsCommandList) и его аллокатором. Предоставляет высокоуровневый API для записи GPU-команд (Draw-вызовы, копирование буферов, установка целей вывода, очистка, изменение барьеров ресурсов) с автоматическим накоплением барьеров переходов состояний (m_ResourceBarrierBuffer).
2. *Владеет*
  - Ссылками на Direct3D-интерфейсы: m_cmdAllocator (ID3D12CommandAllocator) и m_cmdList  - (ID3D12GraphicsCommandList).
  - Списком накопленных барьеров переходов ресурсов m_ResourceBarrierBuffer (std::vector).
  - Временными системными буферами загрузки ресурсов m_TempUploadBuffers, очищаемыми при сбросе   - контекста.
  - Значением забора синхронизации m_fenceValue для контроля завершения со стороны GPU.
3. *Подчиняется*
  - Выделяется и перерабатывается пулом CommandContextPool.
  - Заполняется командами в DirectX12Graphics, Model, Texture и AssetManager.

#### CommandContextPool class
1. *Назначение*
  - Поток-безопасный пул контекстов записи команд (CommandContext). Минимизирует накладные расходы на частое выделение/удаление аллокаторов и списков команд D3D12, повторно выделяя освобожденные контексты только тогда, когда GPU гарантированно завершил их выполнение.
2. *Владеет*
  - Массивом созданных контекстов m_CmdContextPool (std::vector<std::unique_ptr<CommandContext>>).
  - Очередью готовых к выдаче контекстов m_AvailebleContexts.
  - Мьютексом m_Mutex для защиты от гонок потоков.
3. *Подчиняется*
  - Создается в DirectX12Graphics. Из него выделяются контексты кадра и контексты загрузки ассетов.

#### DescriptorAllocator class
1. *Назначение*
  - Менеджер куч дескрипторов (Descriptor Heaps). Решает проблему ручного распределения памяти под дескрипторы D3D12 (указатели на ресурсы для шейдеров, RTV, DSV). Предоставляет слоты дескрипторов по требованию, а освобожденные индексы заносит в очередь переработки m_FreeIndicies.
2. *Владеет*
  - Обернутой кучей Direct3D m_Heap (ID3D12DescriptorHeap).
  - Настройками кучи (тип кучи m_HeapType, максимальный размер, размер шага дескриптора).
  - Очередью свободных индексов m_FreeIndicies (std::queue) для повторного использования.
  - Возвращает дескрипторы в виде структуры DescriptorAllocation, хранящей CPU/GPU хэндлы.
3. *Подчиняется*
  - Создается и используется внутри рендерера DirectX12Graphics.

#### GraphicsCore class
1. *Назначение*
  - Глобальные статические константы рендеринга (размер тройного буфера FrameCount = 3, форматы пикселей буфера кадра и глубины).
2. *Владеет*
  - Не владеет динамической памятью.
3. *Подчиняется*
  - Используется всеми классами RHI.

#### CommandQueue class
1. *Назначение*
  - Обертка над очередью команд Direct3D (ID3D12CommandQueue). Отвечает за отправку записанных списков команд на исполнение видеокарте, установку сигналов синхронизации (Fences) и принудительное ожидание CPU завершения выполнения кадров (блокировка до события забора).
2. *Владеет*
  - Интерфейсом очереди m_cmdQueue (ID3D12CommandQueue).
  - Объектами синхронизации: m_fence (ID3D12Fence), хэндлом события m_fenceEvent и инкрементным значением счетчика забора m_fenceValue.
3. *Подчиняется*
  - Создается и управляется рендерером DirectX12Graphics.
  - Вызывается из SwapChain и AssetManager для отправки команд и ожидания их завершения.

#### PipelineState class
  Является семейством классов, осуществляющих привязку, контроль и переключение состояния ресурсов. Состоит из модулей:
##### PSO
1. *Назначение*
  - Абстрактный базовый класс для хранения скомпилированного состояния конвейера (вычислений или графики).
2. *Владеет*
  - Интерфейсом m_pipelineState (ID3D12PipelineState) и отладочным именем.
3. *Подчиняется*
  - Наследуется модулем GraphicsPSO.
##### GraphicsPSO
1. *Назначение*
  - Инкапсулирует конфигурацию графического конвейера (связка шейдеров, формата разметки вершин, смешивания, режима отсечения граней, тестов глубины и трафарета). Упрощает процесс переключения сложных стейтов отрисовки в Direct3D 12.
2. *Владеет*
  - Структурой описания пайплайна m_psoDesc (D3D12_GRAPHICS_PIPELINE_STATE_DESC).
  - Локальным массивом элементов разметки вершин m_inputLayoutDesc для удержания в памяти до момента вызова компиляции.
3. *Подчиняется*
  - Различные экземпляры GraphicsPSO настраиваются и хранятся в рендерере DirectX12Graphics (основная отрисовка, запись трафарета маски, рендер силуэта/обводки).

#### RootSignature class
  Является семейством классов, осуществляющих привязку, контроль и переключение состояния ресурсов. Состоит из модулей:
##### RootParameter
1. *Назначение*
  - Логическая сущность, представляющая один конкретный слот привязки ресурсов (например, константные буферы, таблицы дескрипторов текстур или непосредственно 32-битные константы) в шейдерах.
2. *Владеет*
  - Объектом CD3DX12_ROOT_PARAMETER.
3. *Подчиняется*
  - Массив этих объектов хранится в RootSignature.
##### RootSignature
1. *Назначение*
  - Описывает структуру связывания ресурсов (констант, текстур, сэмплеров) между CPU-кодом и регистрами GPU-шейдеров. Решает задачу сериализации и создания корневой подписи ID3D12RootSignature.
2. *Владеет*
  - Интерфейсом корневой подписи m_RootSignature (ID3D12RootSignature).
  - Массивом параметров RootParameter (m_RootParams) и статических сэмплеров (m_SamplerDesc).
3. *Подчиняется*
  - Настраивается и создается в DirectX12Graphics. Задается в конвейер при отрисовке через CommandContext.

#### SwapChain class
1. *Назначение*
  - Обертка над системным интерфейсом цепочки буферов вывода (IDXGISwapChain3). Решает задачу смены рендер-буферов (Double/Triple Buffering) перед их выводом на экран дисплея, отслеживает текущий индекс заднего буфера и контролирует кадровую частоту (V-Sync). Регулирует пересоздание экранных буферов при ресайзе окна.
2. *Владеет*
  - Системным интерфейсом цепочки буферов m_swapChain (IDXGISwapChain3).
  - Массивом оберток экранных ресурсов BackBuffer (m_renderTargetsResources).
  - Выделенными дескрипторами RTV (m_rtvAllocations).
  - Значениями заборов кадров для каждого буфера цепочки.
3. *Подчиняется*
  - Инстанцируется внутри рендерера DirectX12Graphics.

#### BackBuffer class
1. *Назначение*
  - Обертка над ресурсом кадра, полученным от Swap Chain. В отличие от других ресурсов, не создает новую область памяти на GPU, а импортирует существующий системный буфер вывода и связывает его с дескриптором RTV.
2. *Владеет*
  - Дескриптором m_RtvAllocation (D3D12_CPU_DESCRIPTOR_HANDLE).
  - Ресурс D3D12 прикрепляется к ComPtr m_pResource через Attach().
3. *Подчиняется*
  - Создаётся и управляется массивом внутри SwapChain.

#### ColorBuffer class
1. *Назначение*
  - Обертка над текстурой рендеринга вне экрана (Render-To-Texture). Позволяет направлять вывод отрисовки геометрии сцены не в экранный буфер окна, а во внутреннюю 2D-текстуру. Создаёт для неё дескриптор цели рендера (RTV) для записи и дескриптор ресурса (SRV) для последующего сэмплирования шейдерами (ImGui-окном вьюпорта).
2. *Владеет*
  - Дескриптором записи m_RtvAllocation (из кучи RTV).
  - Дескриптором чтения m_SrvAllocation (из кучи SRV).
  - Форматом пикселей текстуры.
3. *Подчиняется*
  - Хранится и создается рендерером DirectX12Graphics (m_SceneTexture). Хэндл чтения запрашивается интерфейсом EngineUI.

#### DepthBuffer class
1. *Назначение*
  - Обертка над 2D-текстурой буфера глубины/трафарета (Depth-Stencil Buffer). Отвечает за создание текстурного ресурса с флагом ALLOW_DEPTH_STENCIL и привязку представления (DSV) для использования в тестах видимости и маскирования полигонов.
2. *Владеет*
  - Выделенной аллокацией кучи дескрипторов m_DsvAllocation.
  - Значениями очистки по умолчанию (глубина m_ClearDepth, трафарет m_ClearStencil).
  - Форматом пикселей m_Format.
3. *Подчиняется*
  - Владеет и пересоздает его рендерер DirectX12Graphics.

#### GpuBuffer class
1. *Назначение*
  - Обертка над буферами памяти на GPU (вершинными, индексными или буферами загрузки). Позволяет создавать их как в быстродействующей памяти по умолчанию (Default Heap, невидимой для CPU), так и в разделяемой памяти (Upload Heap, пригодной для записи через Map/Unmap).
2. *Владеет*
  - Размером выделенной памяти m_BufferSize (в байтах).
  - Наследует ID3D12Resource от GpuResource.
3. *Подчиняется*
  - Хранится в Model (как буферы вершин и индексов).
  - Примечание: Дочерний класс GpuConstantBuffer добавляет выравнивание памяти константных блоков на 256 байт.

#### GpuResource class
1. *Назначение*
  - Базовый интерфейс над любым физическим ресурсом в памяти GPU (текстуры, буферы). Хранит COM-указатель на видеопамять и текущее состояние ресурса, используемое системой барьеров.
2. *Владеет*
  - Интерфейсом ресурса m_pResource (ID3D12Resource).
  - Текущим состоянием ресурса в конвейере m_UsageState (D3D12_RESOURCE_STATES).
3. *Подчиняется*
  - Наследуется специализированными классами ресурсов: GpuBuffer, BackBuffer, ColorBuffer, DepthBuffer.
