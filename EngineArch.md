## Annotation

Application/ ← Слой 4
 *Задача*: Создать окно, слушать ввод, использовать нижележащий уровень абстракции
 *Примечание*: Маскимально близко к самой ОС

Framework/ ← Слой 3
 *Задача*: Создать и управлять камерой, хранить массив моделей, использовать нижележащий уровень абстракции
 *Примечание*: Граничный уровень между UI и Graphics API

D3D12Engine/ ← Слой 2
 *Задача*: Вызвать низкоуровневые классы и забрать у них готовый результат
 *Примечание*: Отвечает только за графику. Не знает ни количестве моделей, ни о камере, ни о чем-либо другом

Graphics/ ← Слой 1
 *Задача*: Обеспечить выделение памяти под струтуры и заполнение их данными
 *Примечание*: Самый низкйи уровень. Взаимодействие с GPU, выделение памяти ,создание структур

## Roadmap

1. *Вернуть проект к жизни* - сейчас вся старая архитектура разрушена, необходимо восстановить.
- 1. Написать класс Kernel, который будет собирать воедино высокоурневые механизмы - Window, Input, Framework, Renderer
- 2. Преобразовать класс InterfaceDirectX12 в IRenderer. Сейчас он рассчитан именно на DirectX12 и называется InterfaceDirectX12 соответственно. Тепрь это IRenderer - последняя граница между высоким уровнем UI и низким уровнем Graphics API
- 3. Исправть #include внутри файлов
- 4. Переписать полностью CMakeLists.txt

2. *Работа над framework* - сейчас класс Camera, это мастер-класс, который сам выполняет матричные преобразования. Необходимо разнести логику
- 1. Написать класс Trancform, который и отвечает за математику и сложные преобразования камеры, сама камера использует его и является максимально близким к человеческой логике классом (если я правильно понял)

3. *Работа над загрузкой* - сейчас модель загружается прямо внутри DirectX12 пайплайна, что мешает новой архитектуре.
- 1. Написать класс GameObject - он хранит массив предзагруженных моделей и данные о них (координаты, scale и другие). По идее, пайплайн DirectX12 или любого другого API должен *опрашивать* его и отрисовывать в соответсвии с полученными данными
- 2. Написать класс загрузки текстур для моделй
